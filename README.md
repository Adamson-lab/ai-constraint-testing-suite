# AI Constraint Testing Suite

An automated evaluation framework designed to test Large Language Model (LLM) adherence to strict negative constraints and formatting rules. 

## Project Scope
- **Domain:** Task execution and precise constraint adherence (e.g., course searching agents).
- **Core Focus:** Negative constraints (forbidden words/topics) and structural formatting requirements.
- **Deliverables:** Constraint dataset, automated Python evaluation script, and compliance reporting.

## Methodology
Instead of subjective 1-5 scoring, this suite uses an automated Python pipeline to programmatically verify if the model output violated explicitly forbidden terms or failed to match the requested output structure.
